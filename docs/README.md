# Portfolio Documentation

This directory contains the maintenance documents used to keep Cyrilla's public GitHub account coherent over time.

## Start Here

- [`repository-map.md`](repository-map.md) — defines the role of each public repository: current product, maintenance project, earlier experiment, competition snapshot, or supporting repository.
- [`github-settings-checklist.md`](github-settings-checklist.md) — records repository About metadata, homepage/topic recommendations, profile pins, branch cleanup references, archive guidance, and CI hygiene.
- [`github-profile-readme.md`](github-profile-readme.md) — prepared content for a future `cyrilla-mist/cyrilla-mist` GitHub Profile README repository.

## Maintenance Principle

The Portfolio repository is the public presentation layer, not an archive of every project artifact.

Repository-level technical history stays with the relevant product. This directory only keeps cross-repository presentation and maintenance rules that need one canonical home.
