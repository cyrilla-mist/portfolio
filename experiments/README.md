# Earlier Experiments

This directory is the Portfolio index for smaller standalone product experiments that are no longer maintained as current flagship projects.

The original repositories remain the source of record for their code and Git history. They are intentionally preserved rather than copied into the Portfolio until a safe repository migration is performed.

## Inkraft

AI-assisted writing support for Chinese academic writing workflows.

- Live: https://cyrilla-mist.github.io/inkraft/
- Historical/source repository: https://github.com/cyrilla-mist/inkraft

## PrismAI

A multi-role AI review experiment for comparing feedback from different reviewer perspectives and turning it into prioritized revision actions.

- Live: https://cyrilla-mist.github.io/prism-ai/
- Historical/source repository: https://github.com/cyrilla-mist/prism-ai

These projects are preserved as earlier experiments. New flagship development should happen in the current product repositories rather than extending this collection by default.
